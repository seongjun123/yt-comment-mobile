# 유튜브 댓글 도우미 (모바일 웹앱)

구글 시트에 적어 둔 댓글을 폰에서 버튼 한 번으로 유튜브에 게시하는 개인용 도구입니다.

- 앱 주소: https://seongjun123.github.io/yt-comment-mobile/
- 공식 YouTube Data API · Google Sheets API만 사용합니다. 서버는 없습니다.
- 로그인은 구글 OAuth(리디렉션 방식)로, 1시간짜리 접근 토큰만 브라우저에 저장합니다.

## 시트 형식
1행은 머리글입니다. `댓글` 열과 유튜브 주소가 들어 있는 열이 필요합니다 (유튜브관제탑 CSV + `댓글` 열).
앱이 오른쪽에 `상태 | 게시시각 | 댓글링크 | 게시채널 | 오류 | 공개확인` 열을 자동으로 추가하고 결과를 기록합니다.

`공개확인`: 게시 5분 뒤(1차)와 24시간 뒤(2차)에, 로그인하지 않은 상태 기준으로 댓글이 공개되어 있는지 API 키로 조회해 `보임`/`안 보임`을 기록합니다.
`댓글`이 비어 있거나 `상태`가 `게시 완료`/`건너뜀`인 행은 게시하지 않습니다.

## 파일
- `index.html`, `style.css`, `app.js` — 화면과 동작
- `lib.js` — 순수 로직 (시트 열 찾기, 행 분류, 주소 해석, 오류 해석)
- `config.js` — 웹 OAuth 클라이언트 ID (공개 값)
- `privacy.html` — 개인정보처리방침
- `tests/` — 단위 테스트(`node --test tests/`)와 화면 흐름 테스트(Playwright)
