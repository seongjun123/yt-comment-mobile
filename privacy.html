개인정보처리방침

유튜브 댓글 도우미 (PC 앱 · 모바일 웹앱) · 시행일 2026-10-23

유튜브 댓글 도우미는 운영자 본인이 자신의 유튜브 채널로 댓글을 게시하기 위해 만든 개인용 도구입니다. 누구에게도 서비스를 판매하거나 제공하지 않습니다.

1. 사용하는 구글 데이터

  • 유튜브 (youtube.force-ssl): 로그인한 채널의 이름·프로필 사진 확인, 영상 정보(제목·댓글 허용 여부) 확인, 사용자가 지정한 댓글 게시, 직접 게시한 댓글이 실제로 달렸는지 확인.
  • 구글 시트 (spreadsheets): 사용자가 링크로 등록한 시트에서 영상 주소와 댓글을 읽고, 같은 시트에 게시 결과(상태·시각·댓글 링크)를 기록. 등록하지 않은 시트에는 접근하지 않습니다.
  • 이메일 주소 (openid, email): 어떤 구글 계정으로 로그인했는지 화면에 표시하기 위해서만 사용.

2. 저장 위치

  • 별도 서버가 없습니다. 모든 요청은 사용자의 기기에서 구글로 직접 전송됩니다.
  • 모바일 웹앱: 로그인 정보(1시간 유효)와 시트 목록·설정은 그 기기의 브라우저 저장소에만 보관됩니다.
  • PC 앱: 로그인 정보와 게시 기록은 그 PC의 설치 폴더에만 보관됩니다.
  • 게시 결과는 사용자가 지정한 구글 시트에 기록됩니다.

3. 제3자 제공

구글 데이터를 운영자 외의 누구에게도 제공·판매·공유하지 않으며, 광고나 분석 목적으로 사용하지 않습니다. 이 도구의 구글 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 삭제 방법

  • 모바일 웹앱: 설정 → [모든 로그인 지우기], 또는 브라우저의 사이트 데이터 삭제.
  • PC 앱: [계정 삭제] 또는 설치 폴더 삭제.
  • 구글 계정의 타사 앱 액세스에서 권한을 언제든지 취소할 수 있습니다.
